# IEB IT Paper 2 (Theory) — revision site

A static revision site for IEB Grade 12 Information Technology Paper 2 (theory): topic notes with
comparison tables, a Section A definitions trainer, past-paper question breakdowns with model answers
(written independently, not the official memos), a topic-frequency heatmap, drills and printable cheat sheets.

Not affiliated with or endorsed by the IEB. Past papers and marking guidelines are IEB copyright and are
not included here.

Run locally: `npx http-server .` and open http://localhost:8080.
